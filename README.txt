METAL DETEKTOR — HUB DE ENGENHARIA

COMO ABRIR
1. Extraia o ZIP completo (não mova nem renomeie os arquivos internos).
2. Abra index.html em um navegador atualizado.

ESTRUTURA
- index.html ............................. página inicial do HUB
- styles.css, script.js .................. estilo e script do HUB
- orcamentos/index.html .................. área de Orçamentos
- orcamentos/calculadora-grades.html ..... calculadora de grades (cálculos preservados)
- apresentacoes/index.html ............... lista de apresentações (2 equipamentos)
- apresentacoes/grade-magnetica/ ......... Grade Magnética Automática (3D)
- apresentacoes/sma/ ..................... SMA — Separador Magnético Automático (3D, modelo CAD GLB incorporado)
- assets/ ................................ logo, vídeo, imagens e bibliotecas 3D locais (assets/vendor)

NOVIDADES DESTA VERSÃO
- SMA integrado ao HUB (card 02 em Apresentações).
- Three.js, OrbitControls e GLTFLoader agora são locais (assets/vendor): as simulações 3D funcionam sem internet.
- Link "Voltar" em cada módulo.
- Removidos: versões antigas do HTML 3D, STEP e GLB de origem (o SMA já usa um GLB reduzido embutido no próprio HTML).

OBSERVAÇÃO
Só a fonte Inter (Google Fonts) ainda é carregada da internet; sem conexão o navegador usa uma fonte padrão.
